# HR Analytics Dashboard using Excel

## Project Description
This project focuses on analyzing HR data and building an interactive HR Analytics Dashboard using Microsoft Excel. The dashboard provides insights into employee demographics, workforce distribution, employee attrition, and other key HR metrics to support data-driven decision-making.

## Key Features
- **Employee Overview:** Total employees, active employees, and attrition count.
- **Attrition Analysis:** Analyze employee attrition trends and attrition rate.
- **Demographic Analysis:** Employee distribution based on age, gender, and education.
- **Department Analysis:** Understand workforce distribution across different departments.
- **Interactive Dashboard:** Use Pivot Tables, Pivot Charts, and Slicers for dynamic data analysis.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization

## Objective
To transform raw HR data into meaningful insights through an interactive dashboard, helping organizations understand workforce trends and monitor employee attrition.
